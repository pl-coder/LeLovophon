# Contributing

Keep pitch and average mechanical rotation ratios identical unless a change is explicitly documented. Label CAD concepts, manufacturing drawings and physical test results separately. Preserve the parked and historical designs without presenting them as the current machine.

For a mechanical change, include the relevant dimensions, bought-part reference/drawing, tolerance and assembly implications, updated BOM and a check that meaningfully addresses the failure mode. Record physical test conditions and measured results; do not substitute an animation for a hardware test.

Do not commit media exports, render frames, application runtimes, backups, credentials or personal workspace files. No project licence has been selected; settle intended licensing before accepting third-party contributions.
