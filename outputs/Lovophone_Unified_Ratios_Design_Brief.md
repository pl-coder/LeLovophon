# Lovophone — unified pitch and rotation

The design target is implemented in Lovophone_Unified_160min.FCStd, the Lovophone_Unified MIDI files and Lovophone_Unified_Studio.blend. Earlier chromatic rotation schedules are superseded for this design. See Lovophone_Unified_Setup.md for use and prototype limits.

Pitch and average wheel rotation use the same twelve just-pentatonic ratios to C3:
1, 9/8, 5/4, 3/2, 5/3, 2, 9/4, 5/2, 3, 10/3, 4, 9/2.

The C3 wheel is fixed to the common input axle. Eleven chain stages drive eleven independent picking wheels on a second, stationary axle. Each picking wheel is the same replaceable sheet part, with nineteen integral flexible fingers at floor(32k/19), k=0…18. The balanced 19-of-32 pattern has no shorter rotational symmetry.

The musical wheel configuration repeats after 24 C3-wheel revolutions. A nominal input period of 400 seconds (0.15 rpm) gives a 9,600-second / 160-minute trigger cycle, with 12,825 plucks. The eight-minute MIDI is an excerpt. Both tuning and rhythmic figure are scaled by the same pitch ratio.

The open triangular laboratory frame, implicit bicycle proportions and exposed transmission remain the aesthetic brief. The model fits about 393 × 180 × 177 mm. Routine adjustments target one 2.5 mm Allen key; captive-nut guides and some joints still need detailing.

This is a concept prototype. Exact tooth counts determine average rotation ratios. The supplied chain profiles and chain-travel rendering are references, not validated production engagement. Real chain speed ripple, elastic pick release, motor regulation, torque, acoustics, joints and safety need a physical one-voice test before committing to twelve voices.
