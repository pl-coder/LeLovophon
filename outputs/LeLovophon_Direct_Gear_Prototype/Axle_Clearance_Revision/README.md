# Le Lovophon — crank axle clearance revision

The previous crank axles projected through the connecting-rod plane. The corrected design replaces each separate crank disk and projecting axle with one integral shaft/flange candidate. Its front face ends at station X +4 mm; the connecting rod occupies X +5 to +7 mm. Rotation leaves these X extents unchanged, giving 1 mm continuous axial separation from that crank axle/flange throughout the cycle.

Pitch ratios, tooth counts, crank throws, rod lengths, proportional pendula, phases and the 480-second repeat are unchanged. The original model and films are retained in the author’s local workspace; only this corrected CAD revision is included here. Use the FCStd in this folder.

The original sweep reproduced 553 positive-volume intersections at the twelve crank axles over 360 sampled poses per voice. The revised rod-versus-all-axles sweep has zero intersections and a conservative minimum clearance of 1 mm. The frame/support sweep also has zero intersections at its 72 sampled poses per voice, with no invalid solids. These results are geometric checks, not physical proof.

## Remaining build gates

This is still an engineering prototype, not a manufacturing release. Integral crank shaft/flange fabrication, bearing fits and thrust spacing, gear-to-shaft locking, pin shoulders and retention, phase adjustment, string release force, torque, stiffness, wear and appropriate local gear guards need engineering and bench verification. Existing pin/washer representations remain fastening reservations. See the parent README for the full prototype limitations. The reference STEP and revised candidate BOM are not approved production drawings or purchase instructions.

The local workspace retains the replacement 360-degree films. Their recipes and text reports are included here; media stays local.
